# Changelog

All notable changes to `python-signals` are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the package adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html); before 1.0.0, minor versions may break the API.

## [Unreleased]

## [0.1.0]

### Added

- `IntegerAxis` and `PhysicalAxis` with the index orderings `NATURAL`, `FFT` and `CENTERED`, the position axis and its Fourier conjugates (momentum, angular wavenumber, spatial frequency); sampled `Signal`s and algebraic `AlgebraicSignal`s from Python callables or SymPy expressions, with `PolynomialSignal` and `QuadraticSignal`; arithmetic operators between signals and scalars.
