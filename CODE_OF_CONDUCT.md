# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): participation in it is to be harassment-free for everyone, and contributions and discussions are to be respectful and constructive.

Instances of unacceptable behavior may be reported by opening an [issue on GitHub](https://github.com/BlackWild/qiu/issues/new).
